# Noor UI components

Componentes separados a partir de los gráficos aprobados de la interfaz.

## Carpetas
- `onboarding/`: ilustraciones del walkthrough inicial.
- `home/`: elementos gráficos de la pantalla principal.
- `consent/`: hero, selector, botón de grabación y decoración.
- `insights/`: gráficos y tarjetas de la pantalla de insights.
- `icons/`: iconos individuales.

Todos los componentes exportados están en **PNG con fondo transparente**.
Los archivos `_source_sheet.png` se incluyen solo como referencia visual.

> Nota: el estilo es vectorial, pero los archivos generados son PNG rasterizados, no SVG.
